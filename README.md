# BeautySys

Sistema web para gerenciamento básico de salões de beleza, desenvolvido como **projeto acadêmico em equipe**, com foco em entrega funcional, organização modular e aplicação prática do ciclo completo de desenvolvimento de software.

## 🎯 Contexto do Projeto
O BeautySys foi desenvolvido como trabalho final de disciplina do curso de Tecnologia da Informação, com o objetivo de aplicar conhecimentos de desenvolvimento web full stack, UX, acessibilidade e trabalho colaborativo em um sistema funcional voltado a um problema real de negócio.

O sistema atende às necessidades básicas de organização e gestão de um salão de beleza, considerando requisitos definidos durante o projeto.

## ⚙️ Funcionalidades
- Landing page para acesso ao sistema e dashboard  
- Agendamento de serviços  
- Cadastro e gerenciamento de clientes  
- Controle financeiro (receitas e despesas)  
- Visualização de dados por meio de gráficos  
- Envio de lembretes de agendamento por SMS  
- Dashboard para acompanhamento das informações do negócio  

## 🛠️ Tecnologias Utilizadas
- **Backend:** Python, Django  
- **Frontend:** HTML, CSS, JavaScript, Halfmoon  
- **Banco de Dados:** MySQL  
- **Gráficos:** Highcharts  
- **UX/UI:** Figma (prototipação)  
- **Cloud / Deploy:** AWS  
- **Integrações:** API para envio de SMS  
- **Versionamento:** Git e GitHub  

## 🗂️ Arquitetura e Organização
O projeto foi estruturado em módulos, separando responsabilidades como:
- Agendamento  
- Controle financeiro  
- Gerenciamento de clientes  
- Templates HTML  
- Arquivos estáticos (CSS e JavaScript)

Essa organização teve como objetivo facilitar o entendimento, manutenção e evolução do sistema.

## 🎨 UX, Responsividade e Acessibilidade
Todas as telas do sistema — incluindo a landing page e o dashboard — foram **prototipadas no Figma** antes da implementação.

A aplicação foi desenvolvida com foco em:
- **Design responsivo**, garantindo boa experiência em diferentes tamanhos de tela  
- **Acessibilidade**, seguindo boas práticas de usabilidade e navegação  

## 👥 Trabalho em Equipe
Projeto desenvolvido de forma colaborativa, com divisão de tarefas entre os membros do grupo. Estive presente em todas as etapas do processo, incluindo:
- Levantamento de requisitos  
- Prototipação das interfaces  
- Planejamento da solução  
- Desenvolvimento frontend e backend  
- Deploy da aplicação em cloud (AWS)  
- Testes e validações  
- Documentação final do projeto  

## ▶️ Execução do Projeto
> Projeto acadêmico. A execução pode variar conforme o ambiente.

1. Clonar o repositório  
2. Configurar ambiente Python e dependências do Django  
3. Configurar banco de dados MySQL  
4. Executar a aplicação localmente
